📝 Task Manager – To-Do List

A modern and responsive task management web application designed to help users create, organize, and manage their tasks efficiently.

✨ Features
- ➕ Create and add new tasks
- 📋 Organize tasks into categories/lists
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📅 Set task date and time
- 📊 Dashboard view for task overview
- 📌 Kanban board for task management
- 🗓️ Calendar view
- 🔍 Search and filter tasks
- 🌙 Light and dark theme
- 💾 Persistent task storage
- 📱 Responsive and user-friendly interface

🛠️ Tech Stack
- React
- TypeScript
- Tailwind CSS
- Vite

🚀 Getting Started

1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project

```bash
cd Task-04-To-Do-List
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.
